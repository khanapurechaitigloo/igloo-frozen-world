# v0.5 — Interactive World

## Goals
- Fly-in camera animation on building click
- Penguins + ice hole interaction
- New buildings (ice fishing hut, beer garden)
- Arctic fox ambient creature

## Implementation Order

### 1. Fly-in Camera System
- Save camera state (target, position) before fly-in
- Smooth cubic bezier animation to building hero angle (~1.5s)
- Disable OrbitControls during animation
- Back button / tap empty space to return
- Easing: easeInOutCubic

### 2. Penguin + Ice Hole
- 3 penguin meshes around a circular dark hole on the frozen lake
- Idle: waddle animation (sine wave Y + slight rotation)
- Click penguin → hop → belly flop into hole → pop back up with fish
- Other penguins react (turn toward hole)

### 3. Ice Fishing Hut
- Small wooden shack near the lake
- Fishing rod leaning against it
- Click → fly in, show detail

### 4. Beer Garden
- Ice benches, fire pit with animated flames
- Click → fly in, show detail

### 5. Arctic Fox
- White fox mesh following a patrol path between buildings
- Click → sit, tilt head, run away
